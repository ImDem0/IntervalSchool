# Интервал

Демонстрационная учебная платформа по киберграмотности. Курсы, проверка знаний, материалы и формы работают в браузере. Реальных платежей, аккаунтов и отправки писем нет.

Иванко Сергей Романович — вымышленный автор сценария. Его биография не описывает реального человека.

## Стек

- React 19, TypeScript
- TanStack Start / Router
- Tailwind CSS 4
- Lucide
- Данные курсов и прогресс: локальные модули и `localStorage`

## Запуск

```bash
npm install
npm run dev
```

Сервер разработки слушает порт `8080`.

Проверка типов и сборка:

```bash
npm run typecheck
npm run build
```

## Что уже работает

- Главная, каталог, страница курса, тест, материалы, автор, вопросы и контакт
- Светлая и тёмная тема: системная при первом визите, дальше выбор хранится в браузере
- Поиск, фильтры и сортировка курсов
- Тест с пояснением каждого ответа и рекомендацией
- Отметки уроков и демо-запись — только в `localStorage`
- Контактная форма с проверкой полей и честным сообщением, что отправка не происходит

## Что нужно для настоящей публикации продукта

- Платёжная система и серверное подтверждение заказа
- Учётные записи, если прогресс должен жить между устройствами
- Приём контактной формы (почта или служба поддержки)
- Юридические страницы, если появятся реальные оферта и персональные данные
- Редакция текстов юристом и методистом: сейчас это учебный демо-контент

## Публикация на GitHub

```bash
git init
git add .
git commit -m "Добавить демонстрационную платформу «Интервал»"
git branch -M main
git remote add origin git@github.com:USER/interval.git
git push -u origin main
```

Замените `USER/interval` на свой репозиторий. Секреты в проект класть не нужно: их здесь нет.

Статическая сборка создаётся командой `npm run build`. Хостинг должен поддерживать TanStack Start (в этой среде предусмотрен деплой через Vercel-совместимую сборку).
